# FN Squad — Original Era Archive

> **FN Squad Original Era archive status (November 2026).** This repository preserves the group's earlier gaming website and its historic branding and design. It is **not** the current authoritative FN Squad website.
>
> **Current FN Squad:** https://fnsquadofficial.github.io/
>
> **Historic website:** https://faizzzlol.github.io/freakyniggas/
>
> Some archived wording may be offensive; original historic branding is retained for context, not adopted as FN Squad's present-day public identity.

## Archive maintenance

- The original HTML artwork, animation and gaming pages remain available.
- Archive notices explain that old server IPs, plugin lists, game statuses, example news, links and configuration may be outdated.
- The former Discord webhook token has been removed from the **current** `script.js`. **Revoke the old webhook in Discord**: public Git history and previously cached copies may still contain it. Never put a fresh webhook or API token in front-end code.
- The historic feedback page now creates an email draft to **fnsquadofficial@gmail.com**. It does not submit data automatically and does not claim a message was received before the sender sends it.
- The old Valorant navigation points to an explanatory archive page because no standalone Valorant page was present in the historical source when it was reviewed.
- Changes preserve the original visual identity; the current site handles present-day news, community information and policies.
